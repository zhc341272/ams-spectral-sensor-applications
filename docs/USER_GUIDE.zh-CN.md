# 上位机使用说明

[English](USER_GUIDE.md) · [返回中文首页](../README.zh-CN.md)

## 安装与启动

需要 Python 3.10 或更新版本，Windows 安装包需包含 Tcl/Tk。

```powershell
cd host-software
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python ams_spectral_sensor_app.py
```

也可以运行 `install_dependencies.bat` 安装依赖，再用 `run.bat` 启动。

## 连接设备

1. 接好主板 USB。更换传感器后，应重新断电再上电。
2. 选择主板对应的 COM 口，波特率保持 `115200`。
3. 点击“连接”。程序会自动查询传感器、温度和 LED 状态。
4. 在左侧设备摘要中核对型号、I²C 地址、通道数和固件版本。

常见识别结果：AS7341 为 `0x39 / 10 通道`，AS7343 为 `0x39 / 14 通道`，TCS3448 为 `0x59 / 14 通道`。AS7341 与 AS7341L、AS7343 与 AS7343L 不能只靠身份寄存器区分，L 型号应根据丝印或采购记录选择解析配置。

## 做一次实验

### 1. 填写样品信息

实验名称、样品编号、操作人员和备注会跟随数据写入实验记录和 CSV。样品编号也用于生成默认文件名。

### 2. 选择重复平均次数

可选择 1、3、5 或 10 次。点击“采集并保存实验记录”后，程序连续执行完整四光源测量，并自动保存平均结果。

自动增益可能让相邻两轮使用不同的增益或积分时间。程序会先把每轮数据折算到末次测量的曝光条件，再做平均，因此不会直接混合不同量程的 ADC 数值。

### 3. 查看结果

“实时光谱”是主图，只绘制带典型中心波长的滤光通道。`CLEAR` 和 `FD_RAW` 没有单一中心波长，保留在热图和数值表中。

“数值与分析”显示每一路光源在所有通道上的实际值，并给出：

- 指定波长区间内的峰值和峰值波长；
- 梯形积分结果；
- 按正响应加权的质心波长；
- 亮场或暗场状态标志。

分析区间默认是 400–900 nm，可直接修改。

### 4. 导出

“导出当前数据 CSV”包含实验信息、设备信息、亮场、暗场、净值、当前处理结果、增益、积分时间、温度和状态标志。“保存图像 PNG”保存当前主图。

CSV 使用 UTF-8 with BOM，可直接用 Excel 打开。

## 参考谱、相对响应和吸光度

固件已经为四种光源分别采集配对暗场。需要相对测量时：

1. 放入参考样品或空白样品；
2. 完成一次采集；
3. 点击“将当前测量设为参考谱”；
4. 换入待测样品并重新采集；
5. 在显示方式中选择“相对响应 (%)”或“吸光度”。

处理前会按增益和积分时间归一化：

```text
相对响应 = 100 × 样品净响应 / 参考净响应
吸光度   = -log10(样品净响应 / 参考净响应)
净响应   = 亮场 - 暗场
```

修改传感器配置、通道表、增益、自动增益或积分时间时，参考谱会自动清除，避免用不一致的采集条件计算结果。参考通道为零时，对应结果显示为 `—`。

## 实时采集

填写周期后点击“开始连续读取”，程序会持续刷新主图和稳定性曲线。实时模式不会自动写入实验记录，以免长时间运行产生大量重复数据；需要保留某一时刻时，在“记录与对比”页点击“保存当前测量”。

固件会在上一轮完整结束后再开始下一轮，所以设置过短的周期不会截断当前测量。

## 记录与对比

每次“采集并保存实验记录”的结果会出现在记录表中。可以多选记录并选择 405、白光、850 或 940 nm 光源进行叠加比较。未选择记录时，图中显示最近 8 条。

“导出记录 CSV”采用长表结构，每一行对应一条记录、一个光源和一个传感器通道，适合后续用 Python、R、Origin 或统计软件处理。选择了记录时只导出所选项；未选择时导出全部记录。

## 时间稳定性

每轮完整测量都会加入稳定性序列。纵轴为波长通道净信号总和，并按实际增益和积分时间归一化到每秒，适合检查光源预热、漂移和重复性。稳定性数据可单独导出。

## 设备控制与诊断

“设备控制”页可独立开关四路 LED、执行循环点灯以及查看 NTC 温度。“诊断与配置”页保留传感器身份信息、采集参数、寄存器访问和固件测试命令。

寄存器写入只用于调试。写入前记录原值，试验结束后执行“强制重初始化”或重新上电。

右上角可在中文和 English 之间切换。串口连接、当前数据、参考谱、实验记录、参数和通信日志都会保留。
