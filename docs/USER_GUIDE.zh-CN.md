# 上位机使用教程

[English](USER_GUIDE.md) · [返回中文首页](../README.zh-CN.md)

## 1. 安装

建议使用 Python 3.10 或更新版本。Windows 安装 Python 时需要保留 Tcl/Tk 组件。

```powershell
cd host-software
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python ams_spectral_sensor_app.py
```

也可以直接双击 `install_dependencies.bat`，安装完成后用 `run.bat` 启动。

## 2. 连接和识别传感器

1. 接好主板 USB；更换传感器后应重新断电再上电。
2. 启动上位机。界面默认中文，右上角可以切换 `English`。
3. 选择主板对应的 COM 口，波特率保持 `115200`。
4. 点击“连接”。程序会自动发送 `PING`、`DETECT`、`TEMP` 和 `LED STATUS`。
5. 查看设备摘要：
   - AS7341 通常为 `0x39`，10 通道；
   - AS7343 通常为 `0x39`，14 通道；
   - TCS3448 通常为 `0x59`，14 通道。

“候选型号”是固件真正读到的身份依据，“数据配置”是当前采用的通道解释。手动选择配置只改变数据解释，不能当成芯片精确料号的证明。

## 3. 采集数据

### 读取环境光

“读取环境光”会关闭板载四路 LED，等待暗场稳定时间，再采集一幅独立快照。环境光快照会替换画面中上一轮四光源曲线。

### 四光源完整测量

“四光源完整测量”按 405 nm、白光、850 nm、940 nm 顺序执行。每一路都会：

1. 开启自动增益时，先用该光源做短暂预采样；
2. 关闭所有光源并等待 50 ms；
3. 采集暗场；
4. 只点亮当前光源并等待 50 ms；
5. 采集亮场；
6. 关灯，上报亮场、暗场和状态标志。

图表下方实际值矩阵会显示全部通道：环境光行为原始计数，四路 LED 行为 `亮场 − 暗场` 净值。`—` 表示该光源还没完成，和真实采到 0 不一样。

### 连续采集

填写毫秒周期后点击“开始连续读取”。固件允许的最短周期为 1000 ms。一轮四光源测量本身可能长于设置周期；固件一定会完成当前轮次，再开始下一轮，不会让两轮测量交叠。

## 4. 图表含义

- **暗场扣除后净响应：** 只绘制有典型峰值波长的滤光通道；`CLEAR`、`FD_RAW` 没有单一中心波长，所以不放到 nm 折线上。
- **峰值归一化谱形：** 每一路光源除以自身峰值，适合比较形状，不代表绝对亮度。
- **光源–通道归一化热图：** 保留固件返回的全部通道，每一行单独归一化。
- **有效净信号占亮场比例：** 按波长通道计算 `净值总和 / 亮场总和`。这是有效信号比例，不冒充统计意义上的 SNR。
- **时间稳定性：** 完整轮次结束后，记录净值总和并折算到 1× 增益。
- **NTC 温度监测：** 显示相对时间内的板载温度变化。

如果信号质量图使用红色，表示该光源的亮场或暗场出现模拟饱和、数字饱和或 ASTATUS 饱和。定量使用前应降低光强、积分时间或增益。

## 5. 采集参数

- **自动增益：** 四种光源分别记住自己的增益，不会用白光的增益直接套到 940 nm。
- **固定增益：** 关闭自动增益后生效。AS7341 最大到 512×；AS7343/TCS3448 还提供 1024×、2048×。
- **ATIME / ASTEP：** 共同决定积分时间，界面状态栏显示固件实际报告的微秒数。
- **解析配置：** 正常使用 `AUTO`。只有芯片丝印或采购记录能确认具体光学版本时，才手动选择其他配置。

## 6. LED 与温度页

四路 LED 可以单独开关，用于检查焊接、极性和驱动线路。“循环测试”每路点亮 500 ms，最后自动全部关闭。手动亮灯不包含配对暗场，不能代替定量采集流程。

NTC 区域同时显示 ADC 原始值、电压、电阻和温度。连续测温与光谱连续采集相互独立。

## 7. 配置与测试页

设备详细信息会显示原始 ID、候选型号、寄存器协议和签名值。快速测试包括主板状态、传感器配置、寄存器读写恢复、自检、重初始化、复位、强制采样和完整诊断。

寄存器写入可能让传感器进入异常状态。建议先记下原值、一次只改一个寄存器；试验后使用“强制重初始化”或重新上电恢复。

## 8. 导出

- **导出当前数据 CSV：** 先写设备身份信息，再按通道写环境光以及四路光源的亮场、暗场、净值。
- **导出稳定性 CSV：** 每个完整轮次的每路光源一行，包含增益、状态标志、温度、净值总和、1× 增益折算值和峰值。
- **保存日志：** 保存带时间戳的发送、接收报文。

CSV 使用带 BOM 的 UTF-8 编码，在常用表格软件中打开时中文和通道名不会乱码。

## 9. 切换语言

右上角选择 `中文` 或 `English`。切换时界面控件和图表会重建，但串口连接、传感器身份、当前采样、历史数据、参数和通信日志都保留在内存中。
